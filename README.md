## Object-oriented Programming Principles

### Encapsulation

Bundling data and methods together, restricting direct access to an object's internal state to maintain control.

### Inheritance

Allowing a new class (child) to inherit properties and methods from an existing class (parent), promoting code reuse.

### Polymorphism

Enabling a single function or method to behave differently based on the context, like method overloading or overriding.

### Abstraction

Hiding complex implementation details and exposing only the necessary features, simplifying usage.
